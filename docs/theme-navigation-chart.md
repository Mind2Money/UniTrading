# 1.1.4：主题、导航与图表

> 配色角色、图标、设置分组和桌面入口的现行规则见 [Material 3 界面规范](ui-material3.md)。

## 用户界面

Android 紧凑布局使用 Material 3 `NavigationBar` / `NavigationBarItem`，包含账户、行情、图表、设置四个同级入口；账户页分总览、交易、分析三页，下文的交易页是其中的“交易”页（见 [账户分析](account-analytics.md)）。设置页保留交易商与账户切换、主题、通知和登录管理，并提供独立“活动记录”页面；活动按最新在前显示，返回后回到设置。桌面顶栏也提供设置入口。每个底部入口都有 24 dp 图标、固定文字标签及选中指示背景；应用安全区处理系统导航栏，组件不重复添加底部 inset。参考 [Android Navigation bar](https://developer.android.com/develop/ui/compose/components/navigation-bar)。

交易页使用一个纵向滚动列表，固定按持仓、挂单、历史排列，空分区仍显示标题与空状态。已识别的止损、止盈委托显示在所属持仓行内，带“SL 止损”“TP 止盈”徽标、价格、数量、预计盈亏和撤销按钮，修改走持仓的“止损/止盈”，挂单分区不再重复列出。未成交入场单匹配到的止损、止盈同样显示在该入场单行内，盈亏从入场价算起，修改走入场单的“止损/止盈”；同类括号单有多条、无法匹配到唯一入场单时，仍各占一行。“已识别”指券商接口能确认它是这笔净仓的退出单，同类保护有多条时也算，只是不能改价；关联未确认的订单留在挂单分区，保留“关联待确认”标记和原有编辑限制。历史仍可展开成交明细、定位图表，交易页不显示活动日志。

### 设置页布局

手机和桌面共用分组设置页，使用 M3 列表项和整行点击入口；只有打开新页面的行带右箭头。标题固定，内容独立滚动；账户资金仍在交易页查看。

- **账户与连接**：显示当前账户、交易商、环境和连接状态；点击账户展开交易商与账户列表，选择账户后收起。支持同步账户、添加或重新登录 Tradovate / Rithmic，以及断开当前连接。
- **外观与图表**：主题入口显示当前预设、自定义状态及配色圆点；指标入口显示已配置数量，进入原有编辑器后保存生效。
- **通知**：仅在运行系统盈亏通知服务的平台显示，开关直接生效。
- **记录**：活动记录使用独立页面，保留返回设置入口。
- **已保存的登录**：集中显示本机登录数量、恢复登录和清除登录。清除仍需确认，失败信息保留在分组内。
- **本地模拟**：仅在测试启用本地 Demo 时显示暂停和重置操作，重置仍需确认。

设置页回归测试见 `SettingsPageTest`，涵盖手机/桌面入口、账户列表展开、主题和指标编辑器、活动记录往返、窄屏大字体滚动及重置确认。截图输出到 `artifacts/settings-*.png`。

首次启动显示登录页，不注册本地模拟券商、不加载旧模拟账本。有效的已保存 Tradovate 会话仍会自动恢复；断开最后一个账户或清除所有登录后回到登录页。`demo-broker` 仍是编译依赖，离线测试必须显式传入 `includeDemoBrokers = true`，正式入口不启用，该模块仍包含在构建产物中。

## 主题

登录页和设置页提供主题入口。支持深色、浅色、跟随系统和 TradingV 预设（按 TradingView 黑色主题取色：页面与面板 `#000000`、图表 `#0F0F0F`、网格 `#1C1C1C`、文字 `#B8B8B8` / `#8C8C8C`、强调 `#2962FF`、K 线 `#089981` / `#F23645`、盈亏 `#22AB94` / `#F23645`），独立设置页面/面板背景、图表背景、网格、上涨/下跌 K 线、盈利/亏损数字、文字、强调色和 SL/TP 线颜色。颜色按界面、图表、盈亏数字分组，色块打开 RGB 滑块，也可输入 `#RRGGBB`。

编辑时在对话框预览，保存才写入本机 `theme-v1` 设置；取消不改变现有主题。无效值阻止保存，磁盘失败显示错误并保留现有主题。损坏设置回退到默认配色，不阻止登录。清除登录不影响主题。Android 系统栏图标根据页面背景明暗切换。

盈亏颜色作用于浮动盈亏、持仓、已配对历史成交及下单预估；未知和零值保留普通文字色。K 线颜色与盈亏颜色互相独立。

## 图表

- 图表左上角的品种菜单只列出行情页自选品种，顺序与行情页一致，可按代码或名称筛选；未加入自选的品种需先在行情页添加。从持仓、成交或挂单跳转的合约仍可直接显示。
- 每次切换后立即按交易商保存图表品种，并保存周期；下次启动（含被系统结束后）打开上次的品种和周期。保存的远程品种尚未加载时先显示默认品种，加载后自动切回；服务器搜索不到时放弃恢复，用户手动选择品种也会取消恢复。
- 右侧价格标尺上下滑动缩放价格范围，保持中心价格。
- 底部时间标尺左右滑动调整 K 线密度，按 K 线序号保持视图中心；历史边界会限幅，未严格锚定连续时间轴上的时间点。
- 图表空白区域支持连续横向和纵向平移，保留不足一根 K 线的平移量，允许最新 K 线后留白。
- 重置视图按钮恢复最新 80 根及自动价格范围，切换账户、品种或周期后独立初始化视图。
- 图例、周期/图层工具条和缩放按钮悬浮在图表上，不再占用图表上方的横幅；图例文字区域不拦截平移手势，按钮区域拦截。
- 鼠标悬停、点击或长按显示虚线十字线：竖线对齐指针所在的 K 线位置并在底部时间轴标注其时间（UTC，日线及以上只显示日期），横线跟随指针并在右侧价格轴标注按 tick 取整的价格；横线落在指标副图内时标注该副图的指标值。拖动、Esc 或指针离开图表时隐藏；左右方向键逐格移动时只保留竖线。
- 十字线竖线不停在最新或最早一根 K 线上：指针或方向键移到 K 线之外的留白时，竖线落在该空位，时间按每个空位一个周期顺推（不跳过休市时段，与画图锚点的算法一致）；图例、叠加指标和副图标题此时显示最近一根 K 线的值，在留白处点击不选中历史成交。
- RSI 水平参考线按项目填写，每项包含 0–100 的参考值（最多两位小数）和独立颜色，支持增删与取色器；删除全部项目关闭参考线。重复值或无效颜色阻止保存，旧设置仍保留原有参考值。图中参考线使用自定义颜色绘制虚线。
- 拖动各指标副图上沿的分隔条可调整其与主图的高度比例，其他副图高度保持不变；双击恢复该副图默认高度，聚焦后上下方向键也可调整。比例按指标保存到设备，跨品种、周期和重启保留。主图至少保留可绘制高度的四分之一；新增或重新显示多个副图时，按可用空间收拢其高度。十字线和导航位置同步跟随分隔条。
- 坐标轴手势不命中保护价或挂单线；图表内编辑这些线仍进入原有预览/确认流程。绘制裁剪到图表区域，超出价格范围的标签不挤入坐标轴。
- 水平视图密度限制为 12 至 600 根，实际历史不足时可少于此数；手动价格轴缩放的范围至少为 4 个 tick，自动价格范围另由数据计算。历史边界保留适量空白，不能横向拖到无限远；Tradovate 当前仅缓存最近 2000 根。

Android UI instrumentation 使用独立 `.credentialtest` 应用 ID。登录页使用真实 Activity；图表/导航由测试注入的合成 Demo 数据驱动，不读取真实交易账户、不发送交易。屏幕截图输出到 `artifacts/android-appearance`，Compose 截图输出到 `artifacts/mobile-navigation-chart.png`、`theme-custom-preview.png` 和 `login-light.png`。
