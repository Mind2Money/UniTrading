# 图表画图工具

实现日期：2026-11-09。参照 TradingView 图表左侧工具栏，工具清单、菜单顺序和各工具的默认样式取自 TradingView 页面本身（2026-11-09 读取）。

代码入口：[chart/drawing/](../composeApp/src/commonMain/kotlin/com/unitrading/chart/drawing/)。

| 文件 | 内容 |
| --- | --- |
| `DrawingModels.kt` | 工具清单、分组、默认样式与层级、序列化模型 |
| `DrawingCoordinates.kt` | 锚点（绝对时间 + 价格）与屏幕像素互转、磁铁吸附 |
| `DrawingScene.kt`、`*Geometry.kt` | 每个工具画成哪些线、面、文字；点击判定与绘制用同一份结果 |
| `DrawingRenderer.kt` | 绘制、控制点、轴上标签、点击判定 |
| `DrawingEdit.kt` | 放置后自动补全的点、拖动控制点、整体平移 |
| `ChartDrawings.kt` | 全部状态：工具选择、放置过程、选中、撤销重做、保存 |
| `DrawingLayer.kt` | 接入 `TradingChart`：指针、键盘、光标 |
| `DrawingToolbar.kt`、`DrawingPanels.kt`、`DrawingIcons.kt` | 左侧工具栏、选中工具条、右键菜单、文字与设置对话框、工具图标 |

## 使用

- 桌面端工具栏固定在图表左侧。手机上点图表左缘的小按钮展开或收起，展开后图表相应变窄。
- 点工具按钮武装该工具，再点一次取消；按钮旁的小箭头打开同组工具，按钮显示这组最近用过的工具。长按按钮也能打开菜单。
- 星标加入收藏，收藏的工具显示在图表右下角的小工具条上，可以拖动。
- 放置：逐点点击，鼠标移动时预览下一点。两点工具也可以按住拖动一次画完。路径、折线、模拟 K 线双击或按 Enter 结束，折线点回第一个点时闭合。Esc 取消，右键也取消。
- 选中：点击绘图。拖动控制点改形状，拖动线条或填充区域整体移动。按住 Ctrl 拖动克隆。Delete 删除。Ctrl+Z / Ctrl+Y 撤销重做，工具栏底部也有按钮。Ctrl+C / Ctrl+V 复制粘贴。
- 双击绘图打开设置；带文字的工具双击编辑文字。右键打开菜单：设置、克隆、复制、视觉顺序、锁定、隐藏、移除。
- 在图表空白处（不在绘图和订单线上）点右键，菜单第一项在指针所在价位画一条水平线，价位取最小变动单位，画出后即选中。此时如果绘图处于隐藏状态，会恢复显示。
- 选中后浮动工具条可改颜色、填充、线宽、线型，也能拖开。手机上它在图表底部。
- 触屏上按住未选中的绘图拖动仍是平移图表，轻点选中后才能拖动它，避免滑动时误移绘图。
- 快捷键：Alt+T 趋势线、Alt+H 水平线、Alt+J 水平射线、Alt+V 垂直线、Alt+C 横线、Alt+F 斐波那契回撤、Alt+Shift+R 矩形；图表需要先获得焦点（点一下图表）。按住 Shift 点图表开始测量。
- 磁铁：弱磁铁只在接近 K 线开高低收时吸附，强磁铁总是吸附，可选同时吸附叠加指标。放置时按住 Ctrl 临时反转。

## 保存

- 绘图按品种保存在 `chart-drawings-v1`，工具栏偏好在 `chart-drawing-tools-v1`，与其他设置同一存储；图片按 `chart-drawing-image-<id>` 单独保存。
- 锚点是绝对时间 + 价格，切换周期后位置不变。换账户不影响绘图，相同品种代码共用一份。
- 每个品种最多 1000 个绘图。文件损坏时另存为 `chart-drawings-v1-unreadable` 并提示，不覆盖原文件。
- 每个工具可以保存一份默认设置（2026-11-10 起）：设置对话框底部的“保存为默认”保存当前对话框里的样式（含文字颜色、字号、粗斜体）、层级、对话框里能改的参数（例如回归趋势的偏差、仓位工具的账户规模、K 线形态的模式、艾略特波的浪级）和可见周期，之后新画的同类绘图都从它开始；已经画好的绘图不变。点、文字内容、链接、表情、图片和表格位置属于单个绘图，不保存进默认设置。
- “恢复初始默认”删除这个工具保存的默认设置，并把对话框里的值换回内置设置；点“确定”后当前绘图也改用内置设置。对话框底部写明新画的绘图用的是保存的默认设置还是初始设置。
- 默认设置写在 `chart-drawing-tools-v1` 的 `toolDefaults`；旧版本只保存样式的 `defaults` 仍然生效，直到这个工具保存了新的默认设置或恢复初始默认。

## 与 TradingView 的差异

- 绘图只能放在 K 线主窗格，不能画在指标副图上；垂直线类会穿过副图。
- 帖子和观点只保存你填的链接和文字，显示成指示牌，可用“打开链接”跳转；不拉取 X 或 TradingView 的内容。
- 贴纸是表情符号，TradingView 的插画贴纸不可用。
- 成交量分布图把每根 K 线的成交量按其高低区间均匀摊开，TradingView 用更低周期的数据，数值会有差异。
- 仓位工具的金额用当前品种的点值和手数计算，默认账户规模和风险比例沿用 TradingView（1000、25%），可在设置里改。
- 设置对话框覆盖样式、层级、文字、坐标和可见周期，TradingView 里更细的选项（文字对齐、百分比显示等）没有做。
- 没有对象树（在 TradingView 右侧栏），单个隐藏的绘图从隐藏菜单的“显示已隐藏的绘图”恢复。

## 验证

- 单元测试：`DrawingGeometryTest`、`ChartDrawingsTest`，覆盖全部工具的分步放置、坐标换算、层级计算、撤销重做、保存恢复。
- 界面测试：`DrawingToolbarUiTest` 在真实 `TradingScreen` 上放置、选中、编辑、删除，并打开图标面板、切换标签页、选用符号后放到图表上。
- `DrawingGallery`、`DrawingScreenshots` 把全部工具和工具栏画到本机 `artifacts/drawing-gallery/` 供目视检查：

```bash
./gradlew.bat :composeApp:desktopTest --tests com.unitrading.chart.drawing.DrawingGallery --tests com.unitrading.ui.DrawingScreenshots
```
