# 账户分析与图表交互

账户页整合总览、交易、分析三页，数据跟随顶部所选的交易子账户；切换子账户后分析范围随之重建。手机上它是底部导航的第一项，桌面上由工具栏的“账户总览”在对话框中打开，工作区和独立窗口不受影响。

- **总览**：资金卡片（净值、余额、今日盈亏、浮动盈亏、保证金和快照时间）、“回撤与风险”、已加载历史净盈亏（有净盈亏待确认的记录时显示“—”并写明笔数），以及子账户的持仓和挂单数。
- **交易**：持仓、挂单和历史，顶部是“平仓此子账户”“平仓全部子账户”两个按钮，见[子账户风控](account-risk-lock.md#平仓此子账户平仓全部子账户)。
- **分析**：下文的统计。
- 子账户处于交易锁定、等待券商盈亏数据或风控记录读不出时，三个页签下面显示原因。

手机图表工具栏常驻显示收藏周期并可横向滚动，收藏周期按时长从短到长排列，未收藏的当前周期排在最后；安卓图表支持双指缩放和平移，加入第二根手指时取消未提交的订单线和画线拖动。短横屏使用紧凑导航和交易栏。

## 账户别名

顶部“登录账户”“交易子账户”两个下拉的每一行右侧有铅笔按钮，可以给登录或子账户起别名（最多 30 个字），留空保存即恢复券商的原名。别名按登录区分：子账户的别名属于它所在的登录，两个登录下编号相同的子账户互不影响。

- 别名显示在原来显示账户名的地方：顶部下拉、账户总览、交易分析、设置页、活动记录标题、下单确认框和实时盈亏通知。下拉里登录和子账户的原名、总览和设置页里子账户的原名作为小字保留。
- 只保存在本机的 `account-aliases-v1`，不发给券商，也不在设备之间同步。
- 入口：[AccountAliases.kt](../composeApp/src/commonMain/kotlin/com/unitrading/app/AccountAliases.kt)、[AccountAliasViews.kt](../composeApp/src/commonMain/kotlin/com/unitrading/ui/AccountAliasViews.kt)。

## 统计口径

- 使用实际返回的平仓 `ClosedTrade.netPnlMicros`，不把账户余额变动当作交易盈亏。只统计当前一个子账户，因此只有一种币种。
- 缺失净盈亏显示“待确认”，不当作零或亏损；已知部分仍可统计并明确提示。超出整数计算范围显示“—”。
- 胜率 = 净盈利记录数 / 净盈亏已知记录数，持平计入分母。分批平仓以券商返回的平仓记录为计数单位，不强行重组成完整往返交易。
- 盈利因子 = 总净盈利 / 总净亏损绝对值。有盈利且无亏损显示 ∞；无有效分母且无盈利显示 —。
- 平均盈亏比 = 平均盈利 / 平均亏损绝对值；只有盈利或只有亏损时显示 —。
- 最大回撤按所选记录的平仓累计净盈亏计算，不包含持仓期间的浮动回撤，不代表券商风控回撤。
- 默认按芝加哥自然日统计，可切北京时间或 UTC，并自动处理时区夏令时。自然日并非期货交易所结算日。
- 统计和日历使用券商快照里的平仓记录加上本机缓存的记录（见下节）。无数据的日期为空，不代表已经证明当日没有交易；周汇总只含当前月份。
- 不生成虚构的交易评分、优缺点分析或缺失历史。

## 本机平仓缓存

券商每次只返回一段时间内的平仓记录（Rithmic 登录时取最近 7 天的成交），交易分析因此在本机另存一份：

- 只记录应用运行、并且选中某个子账户时，券商快照里这个子账户的平仓记录，按平仓时间保留 30 天。应用不会向券商补取更早的历史；没有在这台设备上选中过的子账户，以及应用没运行期间平仓、又已超出券商返回范围的记录，都不在缓存里。本地模拟不缓存。
- 合并时以券商快照为准：从快照里最早一笔平仓的时间起，快照里没有的缓存记录（被券商撤回，或换了编号重新配对）删掉，不和替代它的记录重复计数；更早的缓存记录保留；同一编号以券商记录为准，券商这次没给出净盈亏、其余内容相同时，沿用缓存里已知的净盈亏。快照为空时不改动缓存。
- 分析页的页眉写明范围：有缓存时为“券商已同步记录 + 本机缓存（自 <日期> 起，仅含本机运行并选中该子账户时同步到的记录）”，日期按页面所选时区；没有缓存时为“已加载平仓记录”。
- 总览的“已加载历史净盈亏”只用券商快照，不含缓存；缓存里有更早的记录时，两处的数字会不同。
- 保存在应用数据目录的 `analytics-trades-v1`（Windows 为 `%LOCALAPPDATA%\UniTrading\demo-v1\analytics-trades-v1.json`），是明文 JSON，不像已保存的登录那样加密。
- 删除：「设置 → 已保存的登录 → 清除已保存登录」（登录页和空合约页的同名按钮相同）确认后删除全部缓存；断开某个登录（设置里的“断开 <登录>”，或空合约页的“断开连接”）删除这个登录的缓存；卸载应用或清除应用数据也会删除。
- 入口：[AnalyticsTradeCache.kt](../composeApp/src/commonMain/kotlin/com/unitrading/app/AnalyticsTradeCache.kt)、[AccountAnalyticsPage.kt](../composeApp/src/commonMain/kotlin/com/unitrading/ui/AccountAnalyticsPage.kt)。

## 验证边界

测试使用合成行情、账户和注入触摸事件，没有发送真实订单。旋转和双指手势仍需真机验证。统计只分析券商返回的和本机缓存的平仓记录；缺失的净盈亏/手续费不会被补造。缓存的合并和清除只在离线测试中验证过，Tradovate 返回的平仓记录覆盖多长、是否连续没有用真实账户核对。
