# 账户分析与图表交互

账户页整合总览、交易、分析。界面账户数据默认跟随顶部交易子账户；切换子账户后重新建立分析范围。

手机顶部可收藏多个周期并横向滚动切换；安卓图表支持双指缩放和平移，加入第二根手指时取消未提交的订单线/画线拖动。短横屏使用紧凑导航和交易栏。

## 统计口径

- 使用实际返回的平仓 `ClosedTrade.netPnlMicros`，不把账户余额变动当作交易盈亏，不混合不同币种。
- 缺失净盈亏显示“待确认”，不当作零或亏损；已知部分仍可统计并明确提示。超出整数计算范围显示“—”。
- 胜率 = 净盈利记录数 / 净盈亏已知记录数，持平计入分母。分批平仓以券商返回的平仓记录为计数单位，不强行重组成完整往返交易。
- 盈利因子 = 总净盈利 / 总净亏损绝对值。有盈利且无亏损显示 ∞；无有效分母且无盈利显示 —。
- 平均盈亏比 = 平均盈利 / 平均亏损绝对值；只有盈利或只有亏损时显示 —。
- 最大回撤按所选记录的平仓累计净盈亏计算，不包含持仓期间的浮动回撤，不代表券商风控回撤。
- 默认按芝加哥自然日统计，可切北京时间或 UTC，并自动处理时区夏令时。自然日并非期货交易所结算日。
- 日历仅对已加载平仓历史统计。无数据的日期为空，不代表已经证明当日没有交易；周汇总只含当前月份。
- 不生成虚构的交易评分、优缺点分析或缺失历史。

## 秒周期接口

`md/getChart` 使用 `underlyingType=Tick`、`elementSizeUnit=Seconds`、`elementSize=秒数`；分/日周期仍用原有参数。已更新周期缓存键、时间轴、画线、订单流聚合以及设置保存。秒线独立缓存，不与分钟数据混用；不把分钟 K 线拆分成秒线。

参数依据官方接口文档：
https://partner.ninjatrader.com/connect/overview/core-concepts/web-sockets/market-data/market-data-request-reference

真实账户的秒行情能否返回取决于该连接的市场数据权限及服务端支持。本版测试未登录任何真实账户、未发送真实订单，需在目标设备验证。


## 验证边界

测试使用合成行情、账户和注入触摸事件，没有发送真实订单。卓易通真机登录、旋转、双指手势及秒行情权限仍需设备验证。日历只分析已加载的历史记录；缺失的净盈亏/手续费不会被补造。
