# 跟单 Demo 验证版

基于 v1.8.3 主分支的开发版。入口为「设置 → 交易 → 账户跟单」，当前入口被禁用。旧验证逻辑根据账户净仓跟随，会响应其他客户端交易；它与需求不一致，仅供改造参考，不能启用。目标是只跟随 UniTrading 内的主账户交易，支持同登录的 Demo 和 Live、逐笔固定数量或倍率，以及挂单和保护单的完整生命周期。用户要求的完整功能仍在开发，不能将本草稿视作已完成。

旧验证器按净仓变化向跟随账户发市价单，其固定模式不符合要求，必须替换。新规划器按用户确认的规则区分每次成交：固定模式每次部分成交使用固定张数，倍率模式按成交张数计算；主账户平仓时跟随账户平仓，反手先平后开，超过上限或仓位不匹配则停止。限价及止损挂单按相同价格独立提交；各账户成交可能不同步，已独立提交的挂单不再对主单成交重复下市价单。来源登记、持久日志、挂单规划及 Demo 市价/挂单发送服务均为独立原型，目前没有接入交易入口。修改、撤销、保护单关联和异常恢复仍需实现。

订单执行条件使用同一券商账本的快照版本，在命令发送前由 Tradovate 适配器复核；订单标记为自动交易。跟单模式下不允许跟随账户的金额保护自动改写订单。券商数据模型、行情及事件仍需在真实 Tradovate Demo 环境逐项验证；模拟器通过不代表券商支持或实盘可靠。在完整订单生命周期和异常恢复经过验证之前，保持 Live 禁用。

已确认的目标行为：手动启动前所选主账户和跟随账户全部空仓且无挂单；单个跟随账户发生拒绝、结果未知或自身保护单先触发时，只暂停该账户；断线或程序重启后，只有相关账户状态和完整成交记录核对一致、没有未确认操作时才能自动恢复。若主账户状态无法确认，则不能安全恢复任何跟随账户。无效的跟随保护价格不能自动改价或平仓。主账户、跟随账户和各自手数设置应在本机保存；此前已保存的设置不等于启动跟单。

跟单范围为所有合约，每个跟随账户使用自己的固定手数或倍率设置。跟随账户暂停期间的交易不补发；仓位或挂单不一致时保持暂停，须核对处理后才能恢复。这些是目标行为，尚未接入运行时。

新增的主账户保护操作日志、跟随保护执行器、逐账户恢复核对与设置保存目前仍是独立部件，未完成交易界面、成交事件流和断线恢复的端到端联动。Tradovate 的平仓回执可能不含订单 ID；不得将合约 ID 当作平仓订单 ID。券商成交历史的完整性和跨交易日恢复尚未验证，在完成前不能自动补发或声称能自动恢复。
