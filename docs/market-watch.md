# 行情列表与账户角标

行情列表参考 MT5 的紧凑报价布局。左侧显示品种代码和名称，右侧并排显示 Bid（卖出）与 Ask（买入），价格的小数末位加大；底部显示最新报价的 UTC 时间和以最小跳动 tick 计的点差。窄于 360dp 或字体比例超过 1.15 时，品种与报价分行，保留完整价格。

左上角三角标记与相邻文字表示当前账户在该合约上的状态，数字均为笔数：

| 标记 | 数据 |
| --- | --- |
| 多 / 空 | 数量大于零的多头、空头持仓 |
| 挂 | 角色为 ENTRY 的入场挂单 |
| SL / TP | 服务器独立返回的止损、止盈订单 |
| 待 | 角色为 UNRESOLVED 的关联待确认订单 |

同一品种可以同时出现多个标记，三角按状态分色。入场单或持仓上的 SL/TP 价格本身不重复计为独立订单。切换账户后使用新账户快照；平仓、撤单后随快照更新移除对应标记。连续合约使用已解析的实际交易合约匹配报价、持仓与订单，映射缺失时不沿用旧合约的数据。

报价颜色反映该侧报价相对上一笔的升降，Bid 和 Ask 分别计算；首笔报价使用中性色。断连后保留收到的价格和时间，以灰色显示，并标明连接已断开。报价缺失显示 `—`，不会填零。点差按 `(ask - bid) / tickSize` 计算，不把价格的小数位当成 tick。

当前 `Quote` 只提供 Bid、Ask 与时间，未提供日涨跌、前收盘、交易日最高/最低，列表不展示这些字段。选中背景只表示当前图表品种，与持仓标记独立。点行继续打开该品种图表，不发送交易指令。

搜索保留本地按代码、名称过滤及服务器合约查询。标题右侧“标记说明”可查看状态含义、笔数口径、报价颜色和时间单位。页面继续使用现有主题颜色，适用于深色、浅色、TradingV 与自定义主题。

实现：`MarketWatch.kt`（页面及报价行）、`MarketActivity.kt`（账户状态汇总）。测试覆盖角色分离、账户切换、撤单、连续合约映射、报价缺失、点差单位、手机布局、大字体与窄桌面栏。
