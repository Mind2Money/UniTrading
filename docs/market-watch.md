# 行情与自选品种

行情面板按 MT5 参考视频组织：顶部“行情 / ＋ / 编辑”，主体是紧凑的品种、Bid 卖出与 Ask 买入双边报价。末两位价格放大，下面保留报价 UTC 时间和 tick 点差。桌面默认侧栏 320dp，最小 280dp；更窄的独立宿主或大字体使用分行布局，保留完整价格。颜色继续使用现有主题。

“＋”打开添加交易品种页，按连续合约及交易商品种分类浏览。点击分类进入列表，点击右侧加号添加，成功后显示勾选；返回行情后展示自选。编辑页支持上移、下移和移除。移除只改变自选，不操作持仓或订单。列表顺序按交易商保存，切换账户共享该交易商自选，切换交易商隔离；清空列表后重启不会自动补回。

搜索在输入停止 350ms 后自动查询服务器，20 秒超时后可重试。支持 ES、@ES、ES1!；连续合约精确根代码优先，带 @ 或 1! 时只显示连续合约。等价代码共享 30 秒的搜索结果，缺失规格仍会重试；过期后重新查询服务器。名称可过滤已加载目录。目录搜索不再等待主力成交量比较，连续代码在规格加载后即可显示；选择图表或添加自选时再核实实际交易合约。核实过程中保留代码及状态，缺失报价显示 —。

自选列表进入交易界面即恢复并独立订阅实时买卖价，手机切换行情、图表、交易页继续加载和核实。删除自选时，当前图表、持仓和挂单需要的订阅继续保留。恢复自选最多三路发现登录快照尚未包含的合约，每个品种加载后立即进入自身的主力核实，不等全部目录完成；增删和重排保留其他品种的在途查询。合约规格只加载请求涉及的合约，同一实体查询去重，不持有跨品种的加载锁；REST 继续沿用全局节流。单个品种订阅被拒不影响其余品种。连续合约报价来自已解析的实际交易合约；重新核实、核实失败或重启后尚未核实时，继续显示上次成交量确认的实际合约报价，并在副标题标注“核实中”或“待确认”（核实进度 n/m 显示在图表与下单面板）。从未确认过的连续合约没有报价来源，显示 —。下单仍需本次有效的主力验证和实际合约校验，不使用上次结果。

左上角三角标记与文字表示当前账户在该实际合约上的状态，数字均为笔数：

| 标记 | 数据 |
| --- | --- |
| 多 / 空 | 数量大于零的多头、空头持仓 |
| 挂 | ENTRY 入场挂单 |
| SL / TP | 服务器独立返回的止损、止盈订单 |
| 待 | UNRESOLVED 关联待确认订单 |

同一品种可以同时出现多个标记。附在入场单或持仓上的保护价格不重复计为独立订单。切换账户后状态按新账户快照刷新。点击报价行打开图表，不发送交易指令。

Bid 与 Ask 分别按上一笔报价判断升降，首笔中性色；断连保留收到的价格与时间并置灰。点差按 (ask - bid) / tickSize 计算。当前 Quote 未提供日涨跌、前收盘与日高低，不填造视频中这些数值。按 2026-11-02 用户要求，列表底部不再显示品种数、UTC 说明和 ⓘ 标记说明按钮；连接状态由顶栏连接控件显示，列表不重复提示。
